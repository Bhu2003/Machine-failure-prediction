# 🧠 Machine Failure Prediction using CNN

A **predictive maintenance** project that uses **Convolutional Neural Networks (CNN)** to forecast machine failures before they occur.  
This model analyzes sensor data to detect patterns that lead to potential breakdowns — helping industries prevent costly downtime.

---

## 📘 Project Overview
Machine failure prediction plays a key role in **Industry 4.0** and smart manufacturing.  
By leveraging deep learning techniques, this project aims to:
- Identify abnormal patterns in sensor data
- Predict the probability of machine failure
- Support preventive maintenance decisions

## 🧩 Project Workflow
1. **Data Preprocessing**  
   - Cleaned and normalized raw sensor data  
   - Handled missing values and noise  

2. **Feature Engineering**  
   - Extracted time-series features relevant to machine health  
   - Converted readings into image-like arrays for CNN input  

3. **Model Training**  
   - Built a CNN model for classification  
   - Tuned hyperparameters for accuracy and stability  

4. **Evaluation**  
   - Measured accuracy, precision, recall, and F1-score  
   - Visualized confusion matrix and training metrics  

5. **Prediction**  
   - The model predicts whether a machine is likely to fail soon  

---

## 📊 Results
- **Accuracy:** 92.5% (on test dataset)  
- **Precision:** 90%  
- **Recall:** 93%  
- **Model Loss:** Reduced steadily after 15 epochs  
- Visualized with real-time graphs and confusion matrix
